JioHotstar Content Analytics

Project Overview
This project analyzes a sample JioHotstar content dataset to explore content distribution, genre popularity, IMDb ratings, release trends, languages, and countries.

The project demonstrates an end-to-end data analytics workflow using Excel, MySQL, Python, and Power BI.

Business Objectives
- Analyze Movies vs TV Shows distribution.
- Identify popular genres and languages.
- Explore content release trends by year.
- Evaluate average IMDb ratings across genres.
- Understand country-wise content distribution.
- Build an interactive Power BI dashboard for data-driven insights.

Tools & Technologies
- Microsoft Excel — Data analysis and dashboarding
- MySQL — SQL queries and data exploration
- Python — Pandas, data analysis, KPI generation, and report automation
- Power BI — Interactive dashboard and visualization
- Power Query — Data cleaning and transformation
- DAX — KPI measures

Dataset
The project uses a sample dataset containing 100 content records and 12 columns, including:
- Content ID
- Title
- Content Type
- Genre
- Language
- Release Year
- Age Rating
- Duration
- IMDb Rating
- Country

Note: This is a sample dataset used for learning and portfolio purposes. It does not represent official internal JioHotstar data.

Project Workflow

1. Excel Analysis
- Data exploration and cleaning
- PivotTables and PivotCharts
- KPI analysis
- Dashboard creation

2. SQL Analysis
- Data aggregation using GROUP BY
- Filtering using WHERE and HAVING
- Average and maximum rating analysis
- Genre, language, country, and release-year analysis

3. Python Analysis
- Data analysis using Pandas
- KPI calculation
- Data quality validation
- Excel report generation
- Logging and manual automation pipeline

4. Power BI Dashboard
- KPI Cards
- Content Type Distribution
- Titles by Release Year
- Movies vs TV Shows by Year
- Titles by Genre
- Titles by Language
- Average IMDb Rating by Genre
- Content by Age Rating
- Content by Country
- Interactive slicers for Content Type, Language, and Release Year

Key Insights
- Movies account for 66% of the content, while TV Shows account for 34%.
- Romance is the most represented genre, with 14 titles.
- Marathi is the leading language, with 18 titles.
- The year 2022 has the highest release count, with 13 titles.
- Adventure has the highest average IMDb rating of approximately 7.88.
- Drama has the lowest average IMDb rating of approximately 6.25.
- India contributes the highest number of titles, with 25 records.
